2025 · Mobileum Technologies — RAID-TCG Product
Smart Testing — Automated Fraud Test Shoot Engine

Designed and built a fully automated daily shoot generation system for telecom fraud testing — zero manual intervention required. The system combines an ML classification layer with a business logic engine to produce a ready-to-load shoot file for the RAID platform.

ML Layer: Classifies every telecom route into scenarios based on bypass type, validity tier, and pickup pattern. Assigns priority scores and quota weights using 2-month and overall historical lookback periods. Routes are categorised into 6 validity tiers (Good Validity, Bad Validity, Good Historic Validity, Bad Historic Validity, Valid to Others, Limited Historic Data) — each driving a different test frequency and allocation strategy.

Allocation Engine: Distributes daily test quotas across 5 scenario tiers — top affected high-validity routes can receive up to 50–100% of quota; unused routes get minimal monitoring slots. Per-route caps (2–5% for high deliverable >30k, up to 10% for lower volume) prevent over-testing any single route. Max 6 tests per route job, with AdHoc and Recurrent priority rules enforced.

Output: Fully formatted Schedule_Request_TenantID_*.csv shoot file with priorities, call durations, start/end dates, ICPI flags, ForceConnect rules, and quota tracking — ready to load directly into RAID with no human touch.

Impact: 95% reduction in manual effort · F1-score improved by 15% · Data drift monitoring with auto-retraining triggers in production.
